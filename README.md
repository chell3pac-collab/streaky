## Стек

- **Next.js 14** (App Router) + **React 18**
- **TypeScript**
- **SCSS + БЭМ** (блоки разложены по файлам, один блок — один файл)
- Данные: **localStorage** (+ нативный `<progress>` для статистики)

## Возможности

- Добавление привычек: название, иконка-эмодзи, цвет (модификаторы БЭМ)
- Недельная сетка Пн–Вс: отметка дней кликом, будущие дни заблокированы
- Подсчёт текущего стрика (сегодня не отмечено — стрик не «сгорает») и лучшего стрика
- Панель статистики: количество привычек, отметок за неделю, прогресс-бар
- Тёмная/светлая тема: сохранение в localStorage + системная через `prefers-color-scheme`, без мигания при загрузке (inline-скрипт до гидратации)
- Скелетоны на время загрузки данных
- Семантическая разметка и доступность: `header/main/section/article`, `aria-pressed`, `aria-label` на кнопках дней, focus-visible стили, поддержка `prefers-reduced-motion`
- Полный адаптив mobile-first: контейнер через `min()`, перестройка формы на десктопе, недельная сетка 7 колонок на любой ширине

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:3000

## Структура проекта

```
app/
  layout.tsx        — корневой layout: шапка, тема, метаданные
  page.tsx          — главный экран: состояние привычек и обработчики
components/
  Header.tsx        — шапка с логотипом и переключателем темы
  ThemeToggle.tsx   — переключение тёмной/светлой темы
  HabitForm.tsx     — форма добавления привычки
  HabitCard.tsx     — карточка привычки с недельной сеткой
  HabitList.tsx     — список, пустое состояние, скелетоны
  StatsPanel.tsx    — статистика и прогресс недели
lib/
  types.ts          — типы Habit, HabitColor
  dates.ts          — ключи дат, неделя Пн–Вс, подсчёт стрика
  storage.ts        — чтение/запись localStorage + стартовые привычки
  uuid.ts           — генератор id с fallback
styles/
  main.scss         — точка сборки стилей (@use всех блоков)
  globals.scss      — переменные, reset, утилиты (container, visually-hidden)
  blocks/           — по одному SCSS-файлу на БЭМ-блок
```
